# Source-only calibration extension

Temperature is fit on source validation negative log likelihood only. Target test labels are used solely for evaluation. Lower Brier and 15-bin positive-class ECE are better. This is a seed-42 extension, not target-adapted calibration. Zero probabilities are clipped to 1e-7 before temperature scaling.

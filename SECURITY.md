# Security reporting

Report a suspected vulnerability through GitHub's private vulnerability reporting feature when available. If it is unavailable, request a private contact channel from the repository maintainer without posting exploit details or credentials in a public issue.

Include the affected commit, a minimal reproduction, impact and relevant dependency versions. Ordinary research-result disagreements belong in the Result audit issue form.

The active development branch is main. Historical experiment artifacts are retained for reproducibility; fixes should identify affected versions and preserve evidence. Load only trusted local joblib/PyTorch checkpoints. Downloaded LLM files use immutable revisions and remote model code is disabled.
